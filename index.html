VVS runs only while this page is open: a static page cannot run in the background, so on reopening it re-syncs from live sources and never reuses cached prices. Probabilities are heuristic model estimates, not proven odds, and no accuracy is guaranteed. The live price is Polymarket's Chainlink BTC/USD stream (the settlement oracle) with Coinbase BTC-USD as a labelled fallback; candles and indicators come from Coinbase, so a small basis difference is possible and is modeled as uncertainty. History lives in this browser's localStorage and does not sync between devices.
